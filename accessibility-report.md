# Accessibility Audit Report

## 1. Issues Found

I ran a Lighthouse accessibility audit on my personal portfolio website. The audit returned a score of **100/100**, with no accessibility issues reported by Lighthouse.

## 2. Checks Performed

- **Images:** Checked that images have appropriate alternative text.
- **Headings:** Checked the heading hierarchy for a logical structure.
- **Links:** Checked that link text describes its purpose.
- **Language:** Confirmed that the HTML document declares its language using `lang="en"`.
- **Forms:** Checked that form controls have associated labels where applicable.

## 3. Fixes Applied

No Lighthouse-reported accessibility failures required fixing during this audit. The checks above document the accessibility practices reviewed.

## 4. Final Results

- **Final Lighthouse accessibility score:** 100/100
- **Lighthouse-reported issues:** None
- **Remaining considerations:** Automated testing does not identify every possible accessibility problem. Manual keyboard navigation and other accessibility checks are still useful.

## 5. Conclusion

The audit helped me evaluate the accessibility of my portfolio and understand the importance of semantic HTML, descriptive links, image alternative text, and accessible forms. I will continue considering accessibility as I develop more complex websites.
